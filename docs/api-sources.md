# API references and compatibility

Independent adapters based on public API contracts; no implementation code copied from clawarr-suite. Third-party names belong to their projects. Sources consulted for method/route/auth contracts:

- [MCP Python SDK v1 maintenance documentation](https://github.com/modelcontextprotocol/python-sdk/tree/v1.x) — pinned `<2` for tested Streamable HTTP manager API; current security-patched floor 1.30.
- [Sonarr OpenAPI](https://github.com/Sonarr/Sonarr/blob/develop/src/Sonarr.Api.V3/openapi.json), [Radarr API](https://radarr.video/docs/api/), [Lidarr API](https://lidarr.audio/docs/api/), [Readarr API](https://readarr.com/docs/api/), [Prowlarr API](https://prowlarr.com/docs/api/), [Whisparr](https://github.com/Whisparr/Whisparr) — `/api/v3` for Sonarr/Radarr/Whisparr, `/api/v1` for Lidarr/Readarr/Prowlarr. Whisparr v3 movie schema only; older/different forks may require changes. Readarr availability/version varies upstream.
- [Bazarr](https://github.com/morpheus65535/bazarr) — status API, X-API-KEY.
- [qBittorrent WebUI API](https://github.com/qbittorrent/qBittorrent/wiki/WebUI-API-%28qBittorrent-4.1%29), [API key authentication](https://github.com/qbittorrent/qBittorrent/wiki/API-Key-Authentication-%28%E2%89%A5v5.2.0%29) — cookie login for old clients, bearer key for supporting versions, stop/start API naming on recent versions.
- [SABnzbd API](https://sabnzbd.org/wiki/advanced/api) — queue `name=pause/resume&value=NZO_ID`, not global mode pause/resume. Version is public and does not prove authenticated queue access.
- [NZBGet API](https://nzbget.com/documentation/api/) — JSON-RPC and GroupPause/GroupResume.
- [Transmission RPC 4.0.6 compatibility protocol](https://github.com/transmission/transmission/blob/4.0.6/docs/rpc-spec.md) — legacy method names and X-Transmission-Session-Id handshake; modern versions must retain compatibility aliases.
- [Deluge Web JSON API](https://deluge.readthedocs.io/en/latest/reference/web.html) — auth.login cookie, web.connected, core RPC; already-connected daemon required.
- [Overseerr OpenAPI](https://api-docs.overseerr.dev/), [Jellyseerr](https://github.com/Fallenbagel/jellyseerr) — `/api/v1`, X-Api-Key; movie or single-season requests only.
- [Plex API](https://developer.plex.tv/pms/), [Jellyfin API](https://api.jellyfin.org/), [Emby API](https://dev.emby.media/reference/RestAPI.html) — local server token headers; library/session read routes, per-item refresh for Jellyfin/Emby.
- [Tautulli API](https://github.com/Tautulli/Tautulli/wiki/Tautulli-API-Reference), [Autobrr API](https://autobrr.com/api) — bounded allowlisted read commands and health/release/indexer endpoints.
- Helpers: [Recyclarr](https://recyclarr.dev/), [Unpackerr](https://unpackerr.zip/), [Notifiarr](https://notifiarr.com/), [FlareSolverr](https://github.com/FlareSolverr/FlareSolverr), [Gluetun](https://github.com/qdm12/gluetun-wiki/blob/main/content/advanced/control-server.md), [Maintainerr](https://github.com/Maintainerr/Maintainerr), [Tdarr](https://docs.tdarr.io/), [Homepage](https://gethomepage.dev/). Helpers expose only configured endpoint reachability or config presence in this release; API versions/health/metrics may require enabling locally. The bridge never configures VPN, creates solver sessions, runs transcoding tasks or syncs Recyclarr.

Live authenticated health coverage was Sonarr, Radarr, Prowlarr and SABnzbd; discovery also exercised public identities for additional apps. Other adapters have mock contract tests; this is not a claim of physical-stack integration testing for every upstream version. Unsupported routes return a bounded error and are not automatically retried. Before publishing broadly, run a version matrix with disposable service instances.
